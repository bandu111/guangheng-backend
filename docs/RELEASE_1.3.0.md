# GuangHeng 1.3.0 发布说明

- 首页与策略页的待确认方案支持“暂不执行”和“确认执行”，移除不可用的阶段占位按钮。
- 通知入口改为数字角标，并修复窄屏下图标、标题、状态与按钮的布局溢出。
- Android/iOS 接入本地系统通知、默认提示音、振动和桌面角标；点击通知可标记已读、进入策略页并打开方案确认面板。
- 新消息只通知一次，App 恢复前台时立即刷新；通知失败不会影响能源数据加载。
- 模拟器新增满足能量守恒的分时家庭能源模型，夜间和晚高峰负载缺口形成电网购电。
- 模拟器购电功率进入服务器观察存储，并形成购电量、参考电费、日历和报表闭环。
- 初始化最近 7 天的明确模拟历史，真实 Home Assistant 数据不修改、不补造。
- Backend 128 项测试通过；Flutter 静态检查通过，14 项测试通过。
